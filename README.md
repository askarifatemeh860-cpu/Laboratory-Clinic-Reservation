۱.نام ونام خانوادگی:فاطمه عسکری مقدم
شماره دانشجویی:03121174705023
رشته تحصیلی:مهندسی نرم افزار

۲.عنوان موضوع:
این سامانه بستری آنلاین برای جست‌وجو و انتخاب آزمایشگاه‌ها و کلینیک‌ها، مشاهده خدمات و هزینه‌ها و رزرو آسان نوبت در زمان دلخواه کاربران فراهم می‌کند.

۳.مسئله ونیاز:
این محصول با هدف حل مشکلاتی مانند اتلاف وقت برای دریافت نوبت، تماس‌های تلفنی متعدد، شلوغی مراکز درمانی و دشواری در پیدا کردن آزمایشگاه‌ها و کلینیک‌های مناسب طراحی شده است.
هدف اصلی پروژه، فراهم کردن یک سامانه آنلاین است تا کاربران بتوانند به‌راحتی مراکز درمانی را جست‌وجو کنند، خدمات و زمان‌های خالی آن‌ها را مشاهده کرده و بدون نیاز به مراجعه حضوری یا تماس تلفنی، نوبت خود را رزرو کنند

۴.ویژگی های اصلی:
•	ثبت‌نام و ورود کاربران به سامانه
	•	مشاهده و جست‌وجوی آزمایشگاه‌ها و کلینیک‌ها
	•	مشاهده خدمات و اطلاعات مراکز درمانی
	•	مشاهده زمان‌های خالی و انتخاب زمان مناسب
	•	رزرو آنلاین نوبت
	•	امکان لغو یا تغییر زمان نوبت
	•	مشاهده سوابق رزرو توسط کاربران
	•	پنل مدیریت برای مدیریت مراکز و نوبت‌ها

۵. فناوری‌های اولیه پیشنهادی
	•	زبان برنامه‌نویسی: Python
	•	فرانت‌اند (Front-end): HTML، CSS، JavaScript و Bootstrap
	•	بک‌اند (Back-end): Django
	•	پایگاه داده (Database): PostgreSQL
	•	ابزار مدیریت پروژه و نسخه‌ها: Git و GitHub
	•	طراحی رابط کاربری: figma
